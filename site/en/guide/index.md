# Guides

- [Using the models](/en/guide/use): validate JSON with the catalog models, send it to an NGSI-LD broker, and use it as linked data.
  - [GeonicDB](/en/guide/geonicdb): register a model in GeonicDB, then create and query entities.
- [Extending models](/en/guide/extend): extend an existing model for Japan, add your own, the rules, and how to write examples.
- [Contributing](/en/guide/contribute): how to propose, stages and who decides, pull request steps, sign-off (DCO).
- [URLs that never change](/en/guide/urls): the URL contract of this catalog; versions, aliases, caching and IRI resolution.
- [Other data model catalogs](/en/guide/catalogs): catalogs of data models and vocabularies used globally and in Japan, and how this catalog relates to them.
- [Tips & Tricks](/en/guide/tips): match attribute and type names to your own terminology without changing the model, with JSON-LD aliases.
