# 拡張ビルダー

カタログのモデルに、自分のシステムで必要な属性を足すときに使います。モデルを選んで属性を入力すると、次の 2 つのファイルができます。

- **@context**：カタログの `@context` を URL で読み込み、自分の属性だけを定義します。カタログの属性の意味は変わりません。[属性を足す](/guide/extend#writing-a-profile)のプロファイルと同じ書き方です。
- **JSON Schema**：カタログの属性と自分の属性の両方を検証します。カタログのスキーマをその時点のバージョンで丸ごと写したものなので、カタログの新しいマイナーバージョンには追従しません（[属性を足す](/guide/extend#updates)）。

名前空間には、自分が管理するドメインの URL を使ってください。多くのシステムで役に立つ属性なら、カタログへの提案をお願いします（下のリンクから）。入力した内容はこのページの中だけで使われ、どこにも送られません。ただし、提案フォームへのリンクを開くと、入力した属性名と説明が GitHub に送られます（フォームに入力済みの状態で開くため）。
