# 拡張ビルダー

カタログのモデルに、あなたのシステムで要る属性を足すときに使います。モデルを選んで属性を入力すると、次の 2 つのファイルができます。

- **@context**: カタログの `@context` を URL で読み込み、あなたの属性だけを定義します。カタログの属性は IRI が変わりません。[拡張する](/guide/extend#プロファイルの書き方)のプロファイルと同じ書き方です。
- **JSON Schema**: カタログの属性とあなたの属性で検証します。

名前空間には、あなたが管理するドメインの URL を使ってください。多くのシステムで役に立つ属性なら、カタログへの提案をお願いします（下のリンクから）。入力した内容はこのページの中だけで使われ、どこにも送られません。
