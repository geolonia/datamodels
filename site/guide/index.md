# ガイド

## モデルを使う

- [使い方](/guide/use): カタログのモデルで JSON を検証し、NGSI-LD ブローカーに送り、Linked Data として使う。
  - [GeonicDB](/guide/geonicdb): モデルを GeonicDB に登録し、エンティティを作成・検索する。
- [データを変換する](/guide/mapping): 標準に沿ったデータを、対応表（マッピングファイル）を使ってモデルに変換する。
- [属性を足す](/guide/extend): モデルを複製せずに独自の属性を足す。
- [拡張ビルダー](/guide/builder): 独自の属性を足すためのファイルをブラウザで作る。
- [独自の名前で使う](/guide/names): モデルを変えずに、属性名や型名を自分たちの呼び方に合わせる。

## カタログに加わる

- [貢献する](/guide/contribute): 提案の仕方、段階と決め方、Pull Request の手順。
- [モデルのルール](/guide/rules): 独自の型を作るとき、守ること、標準との対応表、例の書き方。

## 参照

- [対応している標準](/guide/standards): 自治体標準オープンデータセットや EEI など、モデルが対応している標準と、それぞれのモデル。
- [URL とバージョン](/guide/urls): どの URL を使うか、何が変わらないか、バージョンと非推奨。
- [他のデータモデルカタログ](/guide/catalogs): 提案の前に確認したい、世界と日本のデータモデルのカタログ。
