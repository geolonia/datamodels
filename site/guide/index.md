# ガイド

## モデルを使う

- [チュートリアル：CSV ファイルから地図まで](/guide/tutorial)：実際のオープンデータを使って、モデルへの変換、ブローカーへの登録、検索、地図への表示までを順に試します。
- [使い方](/guide/use)：カタログのモデルで JSON を検証し、NGSI-LD ブローカーに送り、Linked Data として使う方法です。
  - [GeonicDB](/guide/geonicdb)：モデルを GeonicDB に登録し、エンティティを作成・検索します。
- [データを変換する](/guide/mapping)：標準に沿ったデータを、対応表（マッピングファイル）でモデルの形に変換します。
- [属性を足す](/guide/extend)：モデルを複製せずに、独自の属性を足します。
- [拡張ビルダー](/guide/builder)：独自の属性を足すためのファイルを、ブラウザで作ります。
- [独自の名前で使う](/guide/names)：モデルはそのままで、属性名や型名を自分たちの呼び方に合わせます。

## カタログに加わる

- [貢献する](/guide/contribute)：提案の仕方、段階と決め方、Pull Request の手順です。
- [モデルのルール](/guide/rules)：独自の型を作るときの考え方、守ること、標準との対応表、例の書き方です。
- [拡張を載せる](/guide/list-extension)：モデルに足した属性をモデルのページに載せる方法と、フォームの書き方です。
- [他のカタログを知らせる](/guide/report-catalog)：ここに無いデータモデルや語彙のカタログを知らせる方法と、フォームの書き方です。

## 参照

- [対応している標準](/guide/standards)：自治体標準オープンデータセットや EEI など、モデルが対応している標準と、対応するモデルの一覧です。
- [URL とバージョン](/guide/urls)：どの URL を使うか、何が変わらないか、バージョンと非推奨について説明します。
- [他のデータモデルカタログ](/guide/catalogs)：提案の前に確かめておきたい、国内外のデータモデルのカタログです。
