# 他のカタログを知らせる

「[他のデータモデルカタログ](/guide/catalogs)」に載っていない、データモデルや語彙のカタログを知っていますか？ フォームで知らせてください。メンテナーが確かめてページに載せます。新しく作る前に、ほかの人が見つけられるようになります。

プログラミングは要りません。GitHub のアカウントが要ります。

## カタログとは {#what}

ほかの人が使い回せるデータの定義の集まりです。データモデル、語彙、自治体標準オープンデータセットのようなデータの標準の形など。ログインや契約なしで、誰でも読めるものに限ります。

世界のもの、日本のもの、1 つの組織やプロジェクトのもの、どれでも構いません。datamodels.jp のモデルを拡張したカタログも歓迎します。

## フォームに記入する {#form}

[他のカタログの登録フォーム](https://github.com/geolonia/datamodels/issues/new?template=catalog-report.yml)を開きます。日本語でも英語でも大丈夫です。下の例は、すでに載っているカタログのものです。

| 項目 | 書くこと | 例 |
|---|---|---|
| カタログの名前 | 名前を日本語と英語で | `自治体標準オープンデータセット / Municipal standard open datasets` |
| カタログのページ | 人が読むページの URL | `https://www.digital.go.jp/resources/open_data/municipal-standard-data-set-test` |
| 公開している組織 | 公開している組織 | `デジタル庁 / Digital Agency` |
| 範囲 | 選ぶ：世界、日本、1 つの組織またはプロジェクト | 日本 |
| 内容と形式 | どんな分野のモデルか、どの形式か（JSON Schema、@context、XSD、Excel、CSV など） | `自治体オープンデータの標準フォーマット（公共施設、避難場所、AED など）。CSV の項目定義書` |
| datamodels.jp との関係 | 選ぶ：datamodels.jp のモデルを拡張している、重なるか対応表を作れる、参考になる | 重なる、または対応表を作れる |
| 関係する datamodels.jp のモデル（任意） | サブジェクト/型で | `disaster/EvacuationSite` |
| 機械が読める一覧（任意） | プログラムが読める一覧の URL。`catalog.json` と同じ形式ならそう書く | （空） |
| ライセンス | 例：CC BY 4.0。分からなければ「不明」 | `公共データ利用規約（PDL 1.0）` |
| 公開 | チェック：ログインや契約なしで誰でも読める | チェック |

分からない項目は、分かることだけ書いてください。メンテナーが質問します。

最後に「Create」を押します。

## そのあと {#next}

1. メンテナーがカタログを見て、Issue で質問することがあります。
2. 合えば「[他のデータモデルカタログ](/guide/catalogs)」に載せます。

## このカタログのモデルを拡張したら {#extension}

あなたの組織が datamodels.jp のモデルに属性を足しているなら、そのモデルのページにも載せられます。[拡張を載せる](/guide/list-extension)を見てください。
