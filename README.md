# geonicdb-models

Curated bilingual catalog of NGSI-LD data models for GeonicDB, served at models.geonicdb.com. Extends Smart Data Models with Japanese profiles and Japan-only models.

This repository was scaffolded by Geolonia Backstage.

## Getting started

- Update this README with setup instructions.
- Implement your website code.
- Keep `catalog-info.yaml` up to date.
