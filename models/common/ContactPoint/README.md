# ContactPoint

連絡先 / Contact point (value type)

How to get in touch with a facility or an organisation, as the value of a contactPoint Property: telephone, extension, fax, e-mail, web form, other channels and the postal code. The fields follow the contact columns of the 自治体標準オープンデータセット and GIF's core data model 連絡先, with schema.org ContactPoint terms where the meaning matches.

施設や組織への連絡の方法です。contactPoint 属性の値として使います。項目は、自治体標準オープンデータセットの連絡先の列と、GIF のコアデータモデル「連絡先」に合わせています。
