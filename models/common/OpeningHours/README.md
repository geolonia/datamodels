# OpeningHours

利用できる時間 / Opening hours (value type)

When a facility can be used, as the value of an openingHoursSpecification Property: the days of the week, the opening and closing time, and remarks on exceptions such as holidays. The fields follow the 利用可能曜日, 開始時間, 終了時間 and 特記事項 columns of the 自治体標準オープンデータセット and use schema.org OpeningHoursSpecification terms.

施設を利用できる曜日と時間です。openingHoursSpecification 属性の値として使います。項目は、自治体標準オープンデータセットの「利用可能曜日」「開始時間」「終了時間」「特記事項」の列に合わせています。
