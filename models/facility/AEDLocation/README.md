# AEDLocation

AED の設置場所 / AED location

Where one AED (automated external defibrillator) is installed: one row of the list a municipality publishes as 自治体標準オープンデータセット dataset 08 (AED設置箇所一覧). A subtype of Facility that adds the position in the building, equipment for children, and whether the public can use it.

AED（自動体外式除細動器）1 台の設置場所のデータです。自治体が「AED設置箇所一覧」（自治体標準オープンデータセット 08）として公開する一覧の 1 行にあたります。Facility の下位の型で、建物の中での設置位置、小児用の設備の有無、一般の人が使えるかどうかを足しています。
