# CatalogItem

依頼できる品目 / Catalogue item

One item a provider takes requests for, such as one row of a city's list of bulky waste items and fees. Items it does not take can be listed too, with where to take them instead. With a service time, an amount and skills, the values of a request can be computed from its items. The name and description can be given in several languages (LanguageProperty).

提供者が依頼を受ける品目の 1 つです。粗大ごみの品目と手数料の一覧の 1 行などにあたります。受けない品目も、どこへ持っていけばよいかと一緒に載せられます。作業時間、量、必要な技能を持たせると、依頼の値をここから計算できます。名前と説明は、複数の言語で書けます（LanguageProperty）。
