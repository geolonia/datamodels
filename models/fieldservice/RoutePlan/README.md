# RoutePlan

日ごとのルート / Route plan

The plan of the work of one day in one area: a route per vehicle (the requests in order, with arrival and departure times) and the requests that did not fit. It keeps the result of route optimisation (VRP) software (routes and unassigned) as it is. What was actually driven can be recorded with Smart Data Models FleetVehicleOperation.

ある日、ある地区の作業の計画です。車両ごとのルート（回る依頼の順番と、着く時刻と出る時刻）と、入らなかった依頼を持ちます。ルート最適化（VRP）のソフトウェアの結果（routes と unassigned）をそのまま残せます。計画を実際に走った記録は、Smart Data Models の FleetVehicleOperation で表せます。
