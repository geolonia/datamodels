# DisasterEvent

災害事象 / Disaster event

One disaster event and the whole response to it, such as a typhoon or heavy rain: the unit that bundles reports, actions and closures. The same type as Project in the task subject (an alias, identical IRI), named the way disaster response talks about it.

台風や豪雨など 1 つの災害事象と、それに対する対応全体を束ねる単位。通報・対応業務・通行止めなどが所属する。タスク管理サブジェクトの Project と同じ型（エイリアス、IRI は同一）で、名称だけを災害対応の言い方に合わせている。

- Type IRI: `https://models.geonicdb.com/ns/task/Project` (alias of the task subject’s Project)
- Context: `https://models.geonicdb.com/context/disaster/v2.jsonld` (alias), `https://models.geonicdb.com/context/disaster/v2.1.0.jsonld` (exact)
- Schema: `https://models.geonicdb.com/schema/disaster/DisasterEvent/v2.json`
- Page: https://models.geonicdb.com/models/disaster/DisasterEvent/

Files follow the Smart Data Models layout: `schema.json` (key-values representation, with `x-ngsi`, `x-iri` and `x-geonicdb` annotations), `catalog.yaml` (Japanese and English descriptions), `examples/`, `notes.yaml`, `ADOPTERS.yaml`.
