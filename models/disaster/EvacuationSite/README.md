# EvacuationSite

指定緊急避難場所 / Designated emergency evacuation site

One designated emergency evacuation site (指定緊急避難場所), one row of the list a municipality publishes as 自治体標準オープンデータセット dataset 03. Sites are designated per hazard. Opening status and evacuee counts are in EvacuationShelter, which links here with `site`.

指定緊急避難場所1件。自治体が自治体標準オープンデータセット 03 として公開する一覧の1行にあたる。災害種別ごとに指定される。開設状況と避難者数は EvacuationShelter にあり、`site` でここを参照する。
