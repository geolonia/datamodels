# DesignatedShelter

指定避難所 / Designated shelter

One designated shelter (指定避難所), the master record of a facility where evacuees stay, as municipalities register it and GSI publishes it. Its operation during a disaster is EvacuationShelter, which links here with `shelter`.

指定避難所1か所を表す。避難した人が滞在する施設の基本情報（マスタ）で、市町村が登録し国土地理院が公開する。災害時の運用状況は EvacuationShelter で、`shelter` でここを参照する。
